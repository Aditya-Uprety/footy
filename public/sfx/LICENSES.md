# Sound licenses

Footy ships **no audio files**. Every sound is computed in the browser by
`src/app/soundSynth.ts` (sine sweeps, filtered noise and inharmonic partials)
and played through the Web Audio API by `src/app/audio.ts`.

- Source: original code, written for this project (same license as the rest of the repository).
- No samples, recordings or third-party assets are used, so there is nothing to attribute.

If CC0 or licensed recordings are ever added to this folder, list each file here with its
author, source URL and license before committing it.
